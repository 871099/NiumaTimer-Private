# 牛马打工计时器 v0.2.0

第二个发布版本，2026-10-10。Windows x64 便携包，Qt 6.8.3 / MSVC 2022。

## 新增

- 桌面迷你挂件、托盘、缩放、位置锁定、透明度0–80%、展示区穿透及按钮区输入。
- 工资隐私模式、收入目标、下班和久坐提醒、开机启动选项。
- 六周排班预览：未结算日期的上班、休息、无薪请假、自定义班次例外。
- 番茄专注、严格/日常规则、任务估算与优先级、今日计划、内部/外部打断、等待记录、临时想法与每日复盘。
- 四种离线原创合成声音、音量渐变、定时关闭及专注联动。

## 修正

- 音频独立线程按顺序补充缓冲，停止时排空淡出，设备失败后释放并支持重试。
- 日常启动读取原正式数据，不再默认使用空的隔离预览目录。
- 单实例唤回、启动日志、挂件位置找回；保留既有工资/经验/假期规则。

## 下载与升级

下载 NiumaTimer-0.2.0-windows-x64.zip，完整解压后运行 NiumaTimer.exe。不要只复制EXE。若缺MSVC运行库，运行随包vc_redist.x64.exe。

升级前从托盘退出所有旧版本，否则可能唤回已有旧实例。正式数据沿用 `%APPDATA%\NiumaTimer\牛马打工计时器`，不包含在下载包中。使用同一Windows用户升级可继续读取原记录；曾经隔离预览产生的专注记录仍在独立目录，不自动合并。声音偏好保存在本机，重启默认静音。

## 已知限制与验收范围

- Windows Release已编译；完整交互、声音听感和多DPI穿透行为尚待验收，不能据构建成功认定全部功能通过。
- 环境声为程序合成模拟，不是真实场景录音；Android音频未接入，本次不提供APK。
- 牛马仍为六档姿态加轻微动效；完整逐帧动画、历史回写、备份恢复及年历自动更新未完成。
- 工资属于个人排班估算；年历内置2026安排，后续年度仍需更新。
