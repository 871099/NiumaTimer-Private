# 牛马打工计时器：桌面陪伴开发预览

此包为 2026-10-10 的本地开发预览，尚未上传 GitHub，不替换线上 v0.1.0。

## 使用

完整解压目录后运行 `NiumaTimer.exe`，保留 DLL、qml、platforms 与其他依赖目录。若缺 MSVC 运行库，运行随包的 `vc_redist.x64.exe`。

如果已有预览正在运行，请先在“桌面陪伴”页点击“退出程序”再打开此包；重复启动新版只会唤回已有实例。首次预览的托盘图标问题已修正，此包含修正。

## 新入口

- 顶栏挂件按钮：显示/隐藏桌面迷你挂件。
- 侧栏“桌面陪伴”；窄屏在底部“工具”里进入：缩放、锁定、穿透、关闭收起、开机启动、通知及动效设置。
- 工作时间设置下方“日期排班例外”：六周预览，选日期设置上班、休息、无薪请假或自定义班次。只允许未结算日期。
- 顶栏“显/隐”：隐藏首页、统计与挂件工资，限制查看工资设置。
- 首页下方“今天赚够了什么”：添加和删除收入目标。
- 穿透后请从系统托盘取消；重启自动解除穿透。

当前含姿态切换与呼吸动效，完整逐帧动作、历史回写、备份恢复、年历更新和 Android 交付尚未完成。首个预览窗口和挂件已经实际显示；修正版完整交互待验收。

诊断日志在 `%APPDATA%\NiumaTimer\牛马打工计时器\startup.log`。已有用户工资、任务及经验继续保存在本机，不随包分发。
