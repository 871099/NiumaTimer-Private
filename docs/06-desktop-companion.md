# 桌面陪伴首批实施（2026-10-10）

用户确认按竞品分析开始实施。本批交付桌面常驻、未结算日期例外、收入目标和启动诊断；完整角色逐帧动画、历史回写、备份恢复、年历更新及 Android 交付继续列为后续阶段，不视为完成。

## 架构落点

- `DesktopController`：独立 QObject，管理桌面偏好、托盘、开机启动、窗口恢复、提醒与收入目标。Windows 通过现有 Qt Widgets 提供托盘菜单；其他平台不创建桌面系统对象。
- `MiniWidget.qml`：独立 Qt Quick 工具窗口，绑定同一 `WorkTimer` 快照。可缩放、置顶、拖动、锁定及点击穿透。穿透不持久化，下次启动自动解除；托盘提供取消穿透和找回位置入口。
- `DesktopSettingsPage.qml`：桌面偏好即时保存。无托盘时不允许穿透或关闭后隐藏主窗。
- `WorkTimer`：日期例外持久化在原有工资设置命名空间，六周预览、计薪、经验、历史和跨午夜班次共用班次算法。
- `WorkHistoryStore`：用户明确指定的节假日上班记录带 `manualWork` 标记，不再被官方假期保护误撤销；没有标记的旧假期错误记录仍走原有备份迁移。
- `main.cpp`：Windows 单实例锁与本地唤回；有界启动日志（1 MB 轮换）；界面加载失败显示日志位置。

## 业务边界

日期优先级：个人日期例外 > 已收录的官方放假/调休 > 固定周/大小周。休息与请假均为无薪；自定义班次沿用全局休息区间。例外覆盖次日为休息/请假时，前日跨午夜班次会在零点结束；明确安排假期上班时允许按班次计薪。

只允许修改今天起两年内、未结算日期。旧版累计经验混合人工基数和自动奖励，缺少逐日来源，因此本批不提供旧历史回写，不按工资记录反推扣减旧经验。完整历史修正需要先迁移到可追溯的逐日经验账本。

隐私模式隐藏首页、挂件、统计金额与统计柱高，并阻止查看工资设置和首页工资快捷输入。隐私开关是显示偏好，不是存档加密。

收入目标最多 20 项，金额按整数分比较，不解析带千位分隔符的展示字符串；达成提醒跟随下班提醒开关，启动时不会补发已达成目标。当前支持添加/删除，目标编辑后续补充。

提醒使用校准时间判断下班、下班前 5 分钟与连续工作一小时；系统是否呈现通知取决于 Windows 通知/勿扰设置。开机启动默认关闭，用户开启后写当前用户 Run 项，进入挂件模式；移动程序目录后需重新开启。

现有六档姿态加入轻微呼吸缩放，支持关闭。尚未新增眨眼、打字、哈欠、趴桌循环精灵图，不将呼吸动效宣传为完整角色动画。

## 挂件透明度（2026-10-10）

桌面陪伴页支持0–80%透明度，0%不透明，80%最淡。通过Window.opacity整体淡化，仅作用挂件；DesktopController校验有限数值并限制不透明度0.2–1.0，QSettings保存并启动回读，旧配置缺省1.0。主窗口可随时调整，避免挂件完全不可见。完整视觉与重启回读待验收。

## 展示区穿透与正式记录入口修正

2026-10-10：取消整个窗口的Qt.WindowTransparentForInput标志。DesktopController每16ms按光标逻辑坐标检查顶部与底部控制区；控制区恢复Win32输入，展示区设置透明输入样式，主窗口/托盘可关闭穿透。缩放和高DPI坐标使用QWindow.mapFromGlobal；每次启动穿透仍关闭。实际不同DPI下点击穿透行为待验收。

两个根目录日常启动脚本均读取原正式数据目录；隔离仅在显式传入--isolated-preview时使用，窗口标题明确标注非原记录。本次只读确认正式history有10个日期、隔离history为0；未删除、覆盖或合并历史文件。
